# Image attribution

The public landing page uses genuine road/traffic photography from Unsplash. The image URLs are loaded from the Unsplash CDN and include a local CSS colour fallback if a remote image is temporarily unavailable.

- Hero / road traffic in Pune, Maharashtra: Shubham Dhage, “Cars and buses are driving on a highway at night”, Unsplash. https://unsplash.com/photos/cars-and-buses-are-driving-on-a-highway-at-night-G6CAd6GU0Wk — Unsplash License.
- Secondary road-at-night image: Shubham Shrivastava, “Cars on road during night time”, photographed in Indore, Madhya Pradesh, Unsplash. https://unsplash.com/photos/cars-on-road-during-night-time-GLpCpk4Am6c — Unsplash License.

The current landing page reuses the verified Pune road image in one secondary gallery panel because additional suitable assets could not be retrieved into the local project in this environment. Replace that panel with a locally stored Hyderabad ORR / Indian junction image before public launch if a distinct asset is required.
